# Divya Makkenchery — Personal Portfolio

A personal portfolio showcasing my background in computer science, artificial intelligence, data science, and software development. Built with responsive HTML, CSS, and JavaScript, the site highlights my experience, technical skills, education, and projects.

🌐 **Live Website:** [divyamakk.github.io](https://divyamakk.github.io/)

## Features

- Responsive design for desktop and mobile devices
- Overview of professional experience, education, and technical skills
- Featured projects with links to source code
- Resume access and contact links
- Lightweight implementation with no build step or framework required

## Technologies

- **HTML5** — Page structure and content
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Interactive functionality and mobile navigation
- **GitHub Pages** — Website hosting and deployment

## Run Locally

No Node.js, npm, or build tools are required.

1. Clone or download this repository.

2. Open index.html in your browser.

For a more consistent local preview, you can also use the Live Server extension in Visual Studio Code.

## Deployment

This website is hosted using GitHub Pages. Changes pushed to the main branch are published through the repository's GitHub Pages deployment configuration.
